# 🎬 Movie Box Office Analysis 2022–2025

## 📌 Overview

An end-to-end **Power BI data analysis project** using the Movie Box Office dataset from 2022–2025 to analyze movie performance, box-office revenue, ratings, genres, and yearly trends through an interactive dashboard.

## 🛠️ Tools Used

- 📊 Power BI
- 🔄 Power Query
- 🧮 DAX

## 📁 Project Files

- 📈 Power BI Dashboard
- 📊 Movie Box Office Dataset
